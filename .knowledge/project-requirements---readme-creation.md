# Project Overview
Create a project containing a readme.md file that just has the project name in it.

# Functional Requirements
## README File Creation
- FR-001: A file named `readme.md` must be created in the project root directory.
- FR-002: The content of `readme.md` must contain only the project name (no additional text, formatting, or metadata).
- Acceptance Criteria: The file exists, is named `readme.md`, and its content is exactly the project name string.

# Non-Functional Requirements
- NFR-001: The file must be a valid UTF-8 text file.
- NFR-002: No other files should be created as part of this requirement.

# Assumptions & Constraints
- The project name is "README Project" (default assumption; may need clarification).
- The file should be created in the current working directory.

# User Stories
- US-001: As a project maintainer, I want a readme.md file with the project name so that the project has basic identification.

# Task Breakdown
- TASK-001: Create readme.md file with project name content (assigned to Developer)

# Dependencies
- None

# Ambiguities
- The exact project name is not specified. Defaulting to "README Project" unless clarified.
